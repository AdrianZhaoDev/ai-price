# 邮件系统

面向站点管理员的服务商选择、QQ/163/腾讯云/Amazon SES 配置、VPS 填写与测试
步骤见 [SMTP 邮件配置教程](SMTP_SETUP.md)。

## 功能

- 用户价格订阅成功通知。
- 价格变化通知。
- 一键退订。
- 采集失败管理员告警。
- 每次发送有 delivery 记录，便于去重和排查。

## SMTP

使用 Nodemailer 标准 SMTP，可配置：

- AWS SES SMTP
- 阿里云邮件推送 SMTP
- 腾讯企业邮
- QQ 邮箱
- 163 邮箱
- Gmail
- 自建 SMTP

环境变量：

```dotenv
SMTP_HOST=
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=
SMTP_PASSWORD=
SMTP_FROM="AI Price Atlas <price@example.com>"
ADMIN_EMAIL=
APP_URL=http://localhost:3100
EMAIL_TOKEN_SECRET=
```

`SMTP_SECURE=true` 通常配端口 465；端口 587 一般使用
`SMTP_SECURE=false`。`EMAIL_TOKEN_SECRET` 至少 32 个随机字符，
`APP_URL` 必须是用户可访问的生产域名，否则退订链接无效。

## 用户流程

1. 用户选择产品或具体套餐并填写邮箱。
2. 服务端校验邮箱和基于 IP 的组合限流，随后立即激活订阅。
3. 页面立即显示订阅成功；数据库同时保存待发送状态，成功通知邮件在响应完成后由
   后台发送。
4. 成功通知邮件只告知订阅已生效，并提供一次性退订链接，无需点击确认。
5. 完全相同的邮箱与关注范围不会重复订阅或重复发送成功通知。
6. 新价格需由两次独立采集连续确认，单次波动不会进入正式价格历史或发送邮件。
7. 变化确认后，重新计算该套餐当前与上一轮的人民币最低三档。
8. 只有变动进入或离开最低三档时，发送包含当前最低三档的汇总通知。
9. 邮件底部始终包含退订链接。

如果 Web 进程在后台发送完成前重启，或 SMTP 暂时失败，待发送状态会保留并按退避
时间重试。现有采集 timer 每轮开始前也会清扫到期任务，避免通知永久丢失。每次实际
投递时才生成新的退订 token，数据库始终只保存 token 哈希。

## 安全与送达

- token 保存 SHA-256/HMAC 哈希，不保存明文。
- 旧确认 token 仅为兼容已经发出的历史邮件；新订阅只生成退订 token。
- 防止同一邮箱重复订阅。
- 公开订阅 API 对新订阅和已有订阅返回相同成功结果，避免泄露邮箱关注状态；当前
  页面仍会根据本页已知的首次成功记录阻止二次完全相同提交。
- 同一 IP 24 小时最多提交 10 次，并按关注范围与邮箱组合执行 10/60/120 秒限流。
- 配置 SPF、DKIM、DMARC。
- 发件域名和公开站点域名保持一致。
- 处理退信和投诉，生产环境维护 suppression list。

## 管理员告警

下列事件发邮件：

- 同一来源连续三次失败。
- 套餐数量下降超过 30%。
- 两轮确认后的价格跳变超过 50%。
- 价格通知投递或价格排名处理失败。

采集来源连续三次失败后，同一来源、同一错误类型在一次未恢复故障期间只发送一封
告警；持续失败不会每轮重复发送。来源再次成功采集时，系统会关闭该来源全部未恢复
错误；之后出现新的故障事件才会重新告警。价格跳变超过 50% 时，只有新价格经过
两次独立采集确认后才告警；`A→B→A` 或 `A→B→C` 不发送误报。汇率自身波动只
更新人民币参考，不会被当作官方原价变化发送邮件。

## 订阅管理页面

访问 `/admin` 查看订阅邮箱、通知产品/套餐范围、确认状态和更新时间。管理入口不
使用 URL token 或浏览器本地存储；点击“发送登录验证码”后，系统只向
`ADMIN_EMAIL` 发送 6 位验证码，验证成功后建立 12 小时 HttpOnly 会话。

管理员登录验证码邮件也会写入 `email_deliveries`，类型为
`admin_login_code`，可用于验证 SMTP 实际投递链路。当前只有登录管理员才能读取
订阅邮箱明文。

`/admin/errors` 提供完整采集错误后台，可按错误种类、渠道、处理状态筛选和分页。
页面显示来源、解析器、采集批次、连续失败次数、告警/恢复时间、完整结构化错误、
网络 cause、重试记录、HTTP 响应摘要与修复建议。日志以纯文本渲染并在写入时脱敏，
不需要从 VPS 下载 journal。
