# 测试策略

## 质量门槛

- 行覆盖率不低于 70%。
- 分支覆盖率不低于 70%。
- 函数覆盖率不低于 70%。
- 采集失败、告警和退订路径属于强制覆盖范围。

当前本地基线：语句 78.49%、分支 71.04%、函数 85.63%、行 82.11%。
数据库 SQL 路径由部署环境集成测试验证，不计入纯单元覆盖率分母。

## 测试分层

### 单元测试

- 金额最小单位处理。
- 汇率换算和月均价。
- 套餐归一化。
- 价格变化判定。
- freshness 状态。
- 邮件 token 哈希与过期。
- 主题与展示格式映射。

### 适配器契约测试

每个 adapter 使用本地 fixture，测试：

- 正常解析。
- 字段缺失。
- 套餐新增/删除。
- 币种变化。
- HTTP 错误。
- 页面结构变化。

CI 不实时访问第三方页面，避免外部波动造成随机失败。

### 集成测试

- Repository 幂等写入。
- 相同价格不重复创建变更事件。
- 失败不覆盖最后有效价格。
- 订阅立即生效、重复检测、组合限流和退订。
- 排行榜首次基线、三指标、价格/名次变化、新增/移除和确定性排序。
- 5 小时提交上限、仅一次排行榜兜底及并发互斥。
- 邮件发送写入 delivery 记录，并覆盖失败退避、进程中断后的重新认领和 timer
  兜底重试。
- 管理员告警去重。

采集 runner 使用 mock repository 覆盖成功、HTTP/解析失败、套餐数量骤降、
连续失败升级和大幅价格跳变。

本机还可执行 `npm run test:stability`，连续运行两轮 219 个真实官方来源，并验证
来源成功率、报价数量漂移、重复观测、价格变化误报和持久化运行状态。

### E2E

- 三种模式切换。
- 产品和套餐筛选。
- 官方链接可见。
- 提交邮箱、立即成功和重复订阅状态反馈。
- 排行榜常规订阅、限流确认态、复用邮箱与取消关闭。
- 价格/名次角标的悬浮、键盘、触摸和窄屏无横向溢出。
- 移动端底部 sheet。
- 键盘导航。
- 主题切换。

## CI

每个 Pull Request 执行：

```text
install
lint
typecheck
unit + integration
coverage gate
build
playwright smoke
```

采集工作流与 CI 分离，CI 只使用 fixture。

`main` 分支的成功 CI 还会生成 `production-release` artifact，其中包含同一提交
的 Linux Next.js webpack 构建、源码、锁文件、安装器、提交号和 SHA-256 清单。
生产更新只接受整个 CI run（包括 E2E）成功的 artifact；具体流程见
[`VPS_OPERATIONS.md`](VPS_OPERATIONS.md)。
