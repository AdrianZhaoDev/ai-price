# 免费工具站首轮实施

目标：长期维护有自然流量的免费工具站。根据 2026-09-04 的项目评估，先完成可复用、可分享的订阅地区差价与价格变化工具，再以真实使用决定是否扩展 API 成本计算器。

## 本轮范围

- 修复 MiniMax 现有来源，保留最后有效报价与两轮价格确认。
- 减少 sitemap 冷启动的重复数据库读取，预热实际 sitemap 缓存。
- 在既有产品和套餐页增加两地比较、月付连续 12 个月的参考差额、来源及汇率日期。
- 展示已确认的历史价格变化；没有记录时明确说明，汇率变化不包装为官方降价。
- 提供可分享结果、价格变化入口与 RSS、有限的公开数据导出及方法说明。
- 记录匿名工具使用、来源点击和分享事件，区分本地验证与真实流量；遵守现有隐私同意设置。
- 改进核心页面的可见用途说明、内部术语、互链与交互性能。
- 同步产品和运维文档，完成质量门禁、PR/CI/机器人审核、main 产物发布及生产验收。

## 边界

本轮不扩张模型目录、不更换架构、不新增付费服务、不发送社区推广消息。API 用量计算器、月度内容分发和 90 天增长复评是后续根据真实使用开展的实验，不在此次发布中假定已验证。

## 验证记录

实施和发布过程持续补充具体测试、生产检查和未覆盖项。流量与搜索效果需要完整观察窗口，不能以功能上线宣称增长已达成。

2026-09-04 本地验证：

- 格式、lint、typecheck、`git diff --check` 和原生 webpack 生产构建通过。
- coverage：301 项通过，行覆盖率 82%，分支覆盖率 72.25%。需测试数据库的历史 SQL 用例单独运行通过，事务回滚清除测试记录。
- Playwright：69 项通过、25 项按既有平台/旧排行范围跳过；末轮有一项旧导航测试瞬时失败，单独复跑通过。地区选择、复制、延迟提醒、历史失败/重试、关注套餐及 320–1440px 宽度已验证。
- 本地 PostgreSQL 的两轮价格稳定性验证通过；MiniMax 两次独立采集均为 Token Plan 3 条、Paygo 70 条，第二轮 `changeCount=0`。
- 只读独立审查未发现已证实缺陷。生产、外部事件接收与真实流量仍须按发布记录验收。

统计配置基线：现有 GA4 仅关联旧博客，不属于本站。本站新建独立 `Low Price Radar` 属性和 `Low Price Radar Web` 数据流，衡量 ID 为 `G-PZ0X7MRXFN`，关闭增强型衡量。Cloudflare 现有可选同意用途为 `wIJs`；代码在 CMP 未就绪、无明确同意或任一配置用途被拒绝时不发送工具事件。接收端部署及实际同意/拒绝测试通过前，不声称事件已经采集。

生产验收补充：PR #40 已合并并通过 main 的 CI，提交 `544298d` 已通过标准 VPS 产物发布，807 个页面预热成功。MiniMax 两轮线上复采均为 3 条 Token Plan、70 条 Paygo，零错误、零变价，Neon 同步成功。GA4 实时报告已收到页面访问、历史查看、复制分享和数据下载测试事件；测试访问不能视为自然增长。

验收还发现 Grok 的部分历史 App Store 记录存在无明确账期的十倍往返变化。两次相同价格采集只能确认观察一致，不能消除月付/年付同名歧义。后续保护改动在公共历史读取层排除这种账期待复核的大幅变动，保留原始记录，并同步网页和导出说明；不改写存量价格或断言这些变化一定错误。当前采集的账期消歧仍为后续观察项。
