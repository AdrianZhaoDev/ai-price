## 字段与频率

- 每 4 小时、并发 1。中转每站 2 次 GET（发现 + 报价）。未登录读取，不带用户密钥、Cookie 或认证头。
- 中转人民币成本 = 每 token 美元余额报价 × 分组倍率 ÷ 每人民币获得的美元余额 × 1,000,000；按次不乘 1,000,000。美元余额不是实际美元现金，不伪造官方折扣倍率。
- `ai-transit.v1` 的 `per_request` 图片报价若只提供 `image_size_prices`，按原站尺寸拆成独立按次报价，不取平均值；同时提供 `per_request_usd` 时保留通用按次报价。该映射使用 `sub2api-public-v2`，不把图片价格换算成 token 价格。
- 来源单位、字段或版本变化即拒绝。空分组可忽略，但整站报价为空、数据过期、重复报价或已知数量坍缩不得发布。选定中转来源任一失败保留整批旧数据；两个领域分别处理。
- 监控百分比缺少明确可归因样本量，本轮不导入；模型名、逆向/混合上游声明及服务质量均为商家自报，不宣称独立实测。
