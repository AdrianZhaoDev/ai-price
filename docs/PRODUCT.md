# 产品范围

## 产品目标

为用户提供国内外热门 AI 产品的官方价格参考、来源跳转和价格变动邮件通知。

产品不代购、不提供跨区支付服务，也不保证用户能够在低价地区完成购买。所有价格必须展示来源和最后成功采集时间。

## 目标用户

- 想比较主流 AI 会员价格的个人用户。
- 需要选择 API 模型并估算成本的开发者。
- 希望在降价或套餐调整时收到通知的用户。

比较维度：产品、套餐、storefront、原币价格、人民币参考价、账期、采集时间。

App Store 价与平台官网 Web 价是不同渠道，不允许在同一排行中混合。

### 2. 国内消费者订阅

仅展示能够从官方页面核验的消费者会员或开发者订阅套餐。首版优先接入 Kimi、阶跃星辰、MiniMax Token Plan，以及能够稳定核验的豆包等产品。

没有公开价格、必须销售询价或必须登录且无法稳定验证的产品，保留产品入口但显示“官方未公开固定价”，不填造价格。

对于没有消费者订阅或主要面向开发者的平台，直接展示官方 API 价格单。

每个平台最多展示两个最新可比模型。

## 核心功能

- 三种价格模式切换。
- 按产品、套餐、地区和计费周期筛选。
- 价格原币展示和人民币参考换算。
- 直接跳转官方来源页面。
- 展示最后成功采集时间、数据状态和来源类型。
- 用户按“产品”或“产品 + 套餐”订阅价格变动邮件。
- 用户可一次订阅 API 缓存输入、非缓存输入和输出三个价格排行榜的正式变化。
- 默认生效的订阅、后台成功通知邮件和一键退订。
- 全站价格行展示最近一次正式涨价/降价，API 排行榜展示最近一次名次变化或新上榜。
- 采集失败、解析失效、套餐异常消失时通知管理员。
- 价格历史和变更事件持久化，为后续趋势图准备数据。

## 可比性规则

- 会员订阅与 API 按量计费不得混排。
- Web、App Store、Google Play 是独立渠道。
- 月付、年付、一次性购买分别展示；月均价只是派生字段。
- 促销价、试用价、常规价分别标记。
- 团队席位价和个人价不得混排。
- 原始金额和币种永远保留；汇率只用于展示。
- API 排行只比较标准实时、短上下文、付费的每百万 Token 价格；折扣处理档、
  长上下文、免费层和非 Token 项目不参与排名。
- 对无法确认周期的同名 App Store 项目，必须标记为待审核。

## 首版不做

- 代购、充值、礼品卡交易。
- 自动切换 Apple ID 地区或支付。
- 用户账号体系。
- 商业化、广告和付费会员。
- 复杂预测和购买建议。

## 成功指标

- 页面主要内容在移动网络下快速可用。
- 每个展示价格都能追溯到官方链接。
- 每日两轮采集任务连续成功率不低于 95%。
- 失效数据不会覆盖最后一次有效价格。
- 邮件订阅、确认、通知、退订链路可验证。
- 自动测试行覆盖率和分支覆盖率均不低于 70%。
